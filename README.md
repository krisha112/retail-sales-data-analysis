# Retail Sales Data Analysis

## Overview
A beginner data analytics project exploring retail transaction data using Python. The project investigates product category revenue, average transaction values, and monthly sales trends.

## Objectives
- Compare total revenue across product categories.
- Identify categories with the highest average transaction value.
- Analyse monthly revenue trends.
- Inspect data quality and identify potential limitations.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Key Findings
- Electronics generated the highest total revenue: 156,905.
- Beauty had the highest average transaction amount: approximately 467.48.
- May 2023 recorded the highest monthly revenue: 53,150.
- January 2024 contains only two transactions, limiting month-to-month comparison.

## Skills Demonstrated
Data cleaning and inspection, grouping and aggregation, exploratory data analysis, date-based analysis, data visualisation, and communicating business insights.

## How to Run
1. Open the notebook in Google Colab.
2. Upload the required CSV dataset when prompted.
3. Run the cells from top to bottom.
